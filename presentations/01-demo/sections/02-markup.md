# Разметка слайдов

---

# Слайды разделяются тройным тире

Каждый слайд — кусок markdown между разделителями. Настройки слайда
задаются во frontmatter сразу после разделителя:

```md
---
layout: section
step: 2
---

# Заголовок слайда
```

<Note type="warn" title="Частая ошибка">

Между `---` и первой строкой frontmatter не должно быть пустой строки —
иначе Slidev примет блок за обычный слайд.

</Note>

---

# Два общих лейаута

<CodeExplain>

```md
---
layout: lecture
lecture: 3
subtitle: Подзаголовок
duration: 90min
---
```

<template #explain>

`lecture` — титульный слайд: номер, длительность, подзаголовок и футер
с названием проекта.

Задаётся в headmatter `slides.md`, потому что headmatter и есть
frontmatter первого слайда.

</template>

</CodeExplain>

<Note type="tip">

`layout: section` — разделитель смысловых блоков, принимает `step`
с порядковым номером. Пример — предыдущий слайд.

</Note>

---

# Код и пошаговый показ

Блоки кода подсвечиваются автоматически, номера строк включены
в headmatter (`lineNumbers: true`):

```ts {2-3}
export function greet(name: string) {
  const trimmed = name.trim()
  return `Привет, ${trimmed}!`
}
```

<v-clicks>

- Фигурные скобки после языка подсвечивают строки
- `<v-clicks>` показывает список по шагам — пробелом или стрелкой
- Шаги видны в режиме презентатора: там же счётчик кликов

</v-clicks>
