# Двоеточие перед items обязательно

<CodeExplain ratio="3fr 2fr">

```md
<Checklist :items="[
  'Первый пункт',
  'Второй пункт',
]" />
```

<template #explain>

`:items` — это привязка Vue: значение разбирается как массив.

Без двоеточия строка попадёт в компонент как есть, и список
развалится по буквам — компонент это заметит и предупредит в консоли.

</template>

</CodeExplain>

<Note type="danger" title="Слоты внутри слайда">

Внутри компонента пишите `<template #explain>`, а не `::explain::`.
Сокращение работает только для слотов лейаута — внутри слайда
сборка упадёт с `Element is missing end tag`.

</Note>

# Что проверяют гейты

| Проверка       | Что ловит                                                                           |
| -------------- | ----------------------------------------------------------------------------------- |
| `lint:content` | грабли Slidev: опечатки в лейаутах и компонентах, битый frontmatter, мёртвые ссылки |
| `typecheck`    | типы в пропсах общих компонентов                                                    |
| `lint:spell`   | опечатки в тексте слайдов                                                           |
| `format:check` | единообразие разметки                                                               |
| `build:all`    | презентация действительно собирается                                                |

Всё сразу — `pnpm check`. Перед коммитом запускается автоматически.

<!--
Смысл гейтов: Slidev многое проглатывает молча — неизвестный лейаут,
опечатка в имени компонента, битый frontmatter. Сборка зелёная,
а на проекторе пустое место. lint-content ловит это заранее.
-->

# Ведение занятия

<v-clicks>

- `/presenter` — заметки, следующий слайд, таймер
- Пробел и стрелки — вперёд по шагам, `Shift` — по слайдам целиком
- `o` — обзор всех слайдов, `g` — переход по номеру
- `d` — тёмная тема, `f` — полный экран

</v-clicks>

<Note type="tip">

Удобно открыть два окна: презентаторское себе, обычное на проектор —
слайды синхронизируются автоматически.

</Note>
